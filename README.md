# ระบบงานทะเบียนนักเรียน

โปรแกรมบันทึกข้อมูลนักเรียนและออกเอกสารราชการสำหรับงานทะเบียนในสถานศึกษา เป็นหน้าเว็บไฟล์เดียว (`index.html`) ที่ทำงานเป็น Artifact บน claude.ai

เวอร์ชัน 0.1

## ความสามารถ

- **ทะเบียนนักเรียน** — เพิ่ม แก้ไข ค้นหา กรองตามชั้นและสถานะ ตรวจเลขประจำตัวประชาชน ๑๓ หลัก นำเข้าและส่งออก CSV
- **ที่อยู่แบบแยกช่อง** — บ้านเลขที่ หมู่ที่ ซอย ถนน ตำบล/แขวง อำเภอ/เขต จังหวัด รหัสไปรษณีย์ เปลี่ยนคำย่อ (ต. อ. จ. ม.) เป็นคำเต็มให้อัตโนมัติ
- **ออกเอกสาร**
  - หนังสือรับรองการเป็นนักเรียน
  - หนังสือรับรองความประพฤติ
  - หนังสือรับรองการสำเร็จการศึกษา
  - หนังสือส่งตัวนักเรียน (แบบ พฐ.๑๙/๑) ส่งนักเรียนหลายคนในฉบับเดียวได้ (พี่น้อง/ญาติ)
- **ทะเบียนคุมเอกสาร** — รันเลขที่อัตโนมัติ เริ่มนับใหม่ทุกปีปฏิทิน ดาวน์โหลดซ้ำ และยกเลิกเลขได้
- **ภาพรวม** — จำนวนนักเรียนแยกตามชั้นและเพศ

## รูปแบบเอกสาร

จัดตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖ และที่แก้ไขเพิ่มเติม

- กระดาษ A4 ขอบซ้าย ๓ ซม. ขวา ๒ ซม. ล่าง ๒ ซม.
- ตราครุฑสูง ๓ ซม. (อัปโหลดภาพตราครุฑในแท็บตั้งค่า)
- ตัวอักษร TH Sarabun New ๑๖ พอยท์ ย่อหน้า ๒.๕ ซม. เลขไทย
- หนังสือรับรองตามข้อ ๒๔ / แบบที่ ๑๐ ส่วนหนังสือส่งตัวตามรูปแบบหนังสือภายนอก

ตำแหน่งบางส่วนของแบบที่ ๑๐ และถ้อยคำในหนังสือส่งตัวยังไม่ได้เทียบกับแบบฉบับจริง ควรตรวจกับแบบฟอร์มที่เขตพื้นที่การศึกษาใช้

## การเก็บข้อมูล

ข้อมูลนักเรียนเก็บในฐานข้อมูลของ Artifact (capability `db`) ไม่ได้อยู่ในไฟล์นี้หรือใน repository นี้ เฉพาะผู้ที่ได้รับสิทธิ์ Contributor ขึ้นไปเท่านั้นที่อ่านและบันทึกข้อมูลได้ ข้อมูลนักเรียนเป็นข้อมูลส่วนบุคคลตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. ๒๕๖๒

## ฟอนต์

ฝังฟอนต์ TH Sarabun New (ฟอนต์แห่งชาติ ของ SIPA / กรมทรัพย์สินทางปัญญา) แบบตัดเฉพาะอักษรไทยและละติน สัญญาอนุญาตของฟอนต์อนุญาตให้ใช้ ฝังในเอกสาร และเผยแพร่ได้โดยไม่มีค่าใช้จ่าย
