# ระบบงานทะเบียนนักเรียน

โปรแกรมบันทึกข้อมูลนักเรียนและออกเอกสารราชการสำหรับงานทะเบียนในสถานศึกษา เป็นหน้าเว็บไฟล์เดียว (`index.html`) ที่ทำงานเป็น Artifact บน claude.ai

เวอร์ชัน 0.3

## ความสามารถ

- **ทะเบียนนักเรียน** — เพิ่ม แก้ไข ค้นหา กรองตามชั้นและสถานะ ตรวจเลขประจำตัวประชาชน ๑๓ หลัก นำเข้าไฟล์ Excel/CSV จาก DMC และส่งออก CSV รองรับเลข G
- **ที่อยู่แบบแยกช่อง** — บ้านเลขที่ หมู่ที่ ซอย ถนน ตำบล/แขวง อำเภอ/เขต จังหวัด รหัสไปรษณีย์ เปลี่ยนคำย่อ (ต. อ. จ. ม.) เป็นคำเต็มให้อัตโนมัติ
- **ออกเอกสาร**
  - หนังสือรับรองการเป็นนักเรียน
  - หนังสือรับรองความประพฤติ
  - หนังสือรับรองการสำเร็จการศึกษา
  - หนังสือส่งตัวนักเรียน (แบบ พฐ.๑๙/๑) ส่งนักเรียนหลายคนในฉบับเดียวได้ (พี่น้อง/ญาติ)
- **งานประจำปี** — เลื่อนชั้นสิ้นปีทั้งโรงเรียน (ระบุนักเรียนซ้ำชั้นได้ ย้อนกลับได้), รับย้ายเข้าพร้อมเลขประจำตัวถัดไปอัตโนมัติ, ถังขยะกู้คืนนักเรียนที่ลบ
- **รายงาน** — รายชื่อนักเรียนรายห้อง/แบบเช็กชื่อ, ตรวจข้อมูลไม่ครบก่อนส่ง DMC, สรุปจำนวนนักเรียนตามชั้น อายุ เพศ ความด้อยโอกาส, รายชื่อผู้สำเร็จการศึกษา (ประกอบ ปพ.๓), สมุดคุมการรับย้ายเข้าและจำหน่าย, บัตรประจำตัวนักเรียน — พิมพ์หรือส่งออก CSV ได้
- **ทะเบียนคุมเอกสาร** — รันเลขที่อัตโนมัติ เริ่มนับใหม่ทุกปีปฏิทิน ดาวน์โหลดซ้ำ และยกเลิกเลขได้
- **ภาพรวม** — จำนวนนักเรียนแยกตามชั้นและเพศ

## รูปแบบเอกสาร

จัดตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖ และที่แก้ไขเพิ่มเติม

- กระดาษ A4 ขอบซ้าย ๓ ซม. ขวา ๒ ซม. ล่าง ๒ ซม.
- ตราครุฑสูง ๓ ซม. (อัปโหลดภาพตราครุฑในแท็บตั้งค่า)
- ตัวอักษร TH Sarabun New ๑๖ พอยท์ ย่อหน้า ๒.๕ ซม. เลขไทย
- หนังสือรับรองตามข้อ ๒๔ / แบบที่ ๑๐ ส่วนหนังสือส่งตัวตามรูปแบบหนังสือภายนอก

ตำแหน่งบางส่วนของแบบที่ ๑๐ และถ้อยคำในหนังสือส่งตัวยังไม่ได้เทียบกับแบบฉบับจริง ควรตรวจกับแบบฟอร์มที่เขตพื้นที่การศึกษาใช้

## การเก็บข้อมูล

**เปิดใช้บนเครื่อง (ไม่ต้องใช้ claude.ai):** ดับเบิลคลิก `index.html` เปิดด้วย Chrome หรือ Edge ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น (IndexedDB) ไม่หายเมื่อปิดหน้า แต่จะหายถ้าล้างข้อมูลเว็บไซต์ของเบราว์เซอร์ ให้กด “สำรองข้อมูล” ในแท็บตั้งค่าเป็นประจำ และใช้ “กู้คืนจากไฟล์สำรอง” เพื่อย้ายไปเครื่องอื่น ไฟล์ PDF และ CSV ดาวน์โหลดตามปกติของเบราว์เซอร์

**นำเข้าจากระบบ DMC:** ส่งออกรายชื่อนักเรียนจาก DMC บันทึกเป็น CSV แล้วนำเข้าที่แท็บ “ทะเบียนนักเรียน” ได้ทันที โปรแกรมข้ามบรรทัดวันเวลาที่สร้างรายงาน แยกเลขประจำตัวประชาชนออกจากเลขประจำตัวนักเรียน และรวมคำนำหน้า ชื่อ นามสกุลของบิดา มารดา ผู้ปกครองให้

**เปิดใน claude.ai:** ข้อมูลนักเรียนเก็บในฐานข้อมูลของ Artifact (capability `db`) ไม่ได้อยู่ในไฟล์นี้หรือใน repository นี้ เฉพาะผู้ที่ได้รับสิทธิ์ Contributor ขึ้นไปเท่านั้นที่อ่านและบันทึกข้อมูลได้ ข้อมูลนักเรียนเป็นข้อมูลส่วนบุคคลตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. ๒๕๖๒
